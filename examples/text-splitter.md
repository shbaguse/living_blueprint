# Example — Text Splitter

This is a concrete example of the working loop rather than a claim that the example proves a universal methodology.

## Observed workflow

```text
Build
  ↓
Run
  ↓
Encounter limitation / failure
  ↓
Evaluate the actual behavior
  ↓
Identify the improvement needed
  ↓
Ask another AI to help analyze or implement the change
  ↓
Implement
  ↓
Run again
```

The important point is that the next improvement was driven by behavior observed from the running implementation rather than by trying to predict every possible future requirement before building it.

This example should evolve if later evidence shows that the actual workflow differs or reveals a useful additional rule.
