# Living Blueprint — Agent Entry Point

This repository contains the canonical Living Blueprint working rules.

Before performing consequential work, read:

- `CORE.md`
- `PRACTICE.md`
- `UNKNOWN.md`

Use `HISTORY.md` for historical context when needed.

Default behavior:

1. Understand the actual task and its boundaries.
2. Define the minimum useful result.
3. Build or perform the smallest useful action.
4. Run or observe the result when possible.
5. Identify real gaps from observed evidence.
6. Research only when the real gap requires it.
7. Make the smallest justified change.
8. Run or verify again.
9. Stop when the requirement is sufficiently satisfied or further work is not justified.

Do not:

- invent requirements or authority;
- treat assumptions as facts;
- research indefinitely before useful work;
- add speculative complexity;
- ignore contradictory evidence;
- treat implementation as proof of correctness;
- continue work merely because effort has already been invested.

UNKNOWN must remain explicit when evidence is insufficient.

This file is an agent-facing entry point. It is not a separate source of truth from the canonical documents above.
